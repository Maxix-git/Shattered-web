SHATTERED SMP — WEBSITE DEPLOY (Vercel)
=======================================

WHAT'S NEW IN THIS BUILD
- Factions: all clan terminology renamed to Factions everywhere
  (routes are now /factions, /factions/$name; nav says Factions).
- Shard: the floating server-assistant chat bubble is back (bottom-right),
  wired through the API's /v1/assistant/chat. Set ASSISTANT_NAME=Shard on Render.
- Dashboard: "Link your Minecraft account" — enter the 6-char code from /link.
- Data layer talks to the Shattered API (Render) via POST /api/site/rpc.

STEP 1 — VERCEL SETUP
Replace the old Next.js project contents with this folder in your GitHub repo
(Shattered-web). In the Vercel project settings:
- Framework preset: Other (or Vite)
- Build command:    NITRO_PRESET=vercel npm run build
- Install command:  npm install
- Output directory:  .output/public   (the nitro vercel preset writes the rest
  to .vercel automatically — do not change it manually)

STEP 2 — VERCEL ENV VARS
- SITE_API_URL           = https://shattered-api.onrender.com
- SITE_API_KEY           = SAME value as SITE_API_KEY on Render (shared secret)
- SESSION_SECRET         = random long string:  openssl rand -hex 32
- DISCORD_CLIENT_ID      = from the Discord developer portal
- DISCORD_CLIENT_SECRET  = from the Discord developer portal
- DISCORD_CALLBACK_URL   = https://shatteredsmp.vercel.app/auth/callback
- PUBLIC_HOST            = shatteredsmp.vercel.app
- ADMIN_DISCORD_IDS      = your Discord ID
- MC_HOST / MC_PORT      = your Minecraft server (optional; powers the live
                           status badge — the site pings the server itself)

STEP 3 — DISCORD OAUTH
In the Discord developer portal, add redirect URL:
  https://shatteredsmp.vercel.app/auth/callback

STEP 4 — VERIFY
- Home page renders with live players/kill feed (or honest empty state if the
  API isn't up yet).
- Sign in with Discord works.
- Shard bubble replies (stub answers until the LLM key is wired later).
